# 0.1.4 — 接入常驻 Agent 管理入口

聊天区顶部新增「Agent 管理」，直接打开 MindFS 原有菜单，窄工具窗口里也能使用：

- 添加 Agent 配置。
- Agent 配置切换重启，包括在列表中单独重启所选 Agent。
- Agent 安装和更新，查看「已识别 / 未检测到」状态和已获取的版本。
- 刷新 Agent 列表；请求失败显示错误，可再次刷新。

继续使用 MindFS 的原有配置、安装命令会话、Agent 检测器及重启接口。重启触发原有重新探测，刷新列表读取当前检测结果。保留 0.1.3 的 Mac shell 环境修复和既有原生交互行为。

| 平台 | 下载 |
| --- | --- |
| Mac，Apple 芯片 | [macos-arm64.zip](https://github.com/zhuxian89/idea-ai-agent/releases/download/v0.1.4/idea-ai-agent-0.1.4-macos-arm64.zip) |
| Mac，Intel | [macos-amd64.zip](https://github.com/zhuxian89/idea-ai-agent/releases/download/v0.1.4/idea-ai-agent-0.1.4-macos-amd64.zip) |
| Windows x64 | [windows-amd64.zip](https://github.com/zhuxian89/idea-ai-agent/releases/download/v0.1.4/idea-ai-agent-0.1.4-windows-amd64.zip) |

在 IDEA 的 Settings → Plugins → 齿轮 → Install Plugin from Disk 选择 ZIP，安装后重启 IDEA。继续覆盖 IDEA 2024.1、2024.2、2024.3；Mac 包要求 macOS 12+，使用对应架构的 IDEA。

浏览器验证覆盖入口、配置选择、重启请求与失败重试、识别状态、刷新错误处理及 375px 窄窗口和明暗主题。测试使用受控接口响应，没有执行真实 CLI 安装、配置写入或模型调用。Mac 包为交叉编译产物，仍需 Mac 实机确认。
