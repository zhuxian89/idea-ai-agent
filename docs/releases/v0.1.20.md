# 0.1.20 — Windows 与 macOS 四种架构

补齐 Windows ARM64 与 Intel Mac 原生运行程序。本版本覆盖 Windows x64、Windows ARM64、macOS Apple Silicon 和 macOS Intel，并提供一个可直接上传 JetBrains Marketplace 的通用插件 ZIP。

- 最大限度还原本机 Agent 的原生能力，并继续保持零配置接入。
- GitHub Release 提供四个体积更小的单平台安装包。
- `idea-ai-agent-0.1.20.zip` 是 Marketplace 通用包，内部包含四个运行程序；用户只需安装这一个 ZIP，插件会自动选择匹配当前系统和 CPU 的程序。
- 最低支持 IntelliJ IDEA 2024.1，不设置最高版本限制。
