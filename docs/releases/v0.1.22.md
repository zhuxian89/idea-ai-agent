# 0.1.22 — 语音输入与文件变更查看

新增语音转文字：点击输入区麦克风录音，停止后把识别结果插入原光标位置，保留草稿，不自动发送。

- 支持腾讯云、硅基流动和自定义语音服务。首次默认腾讯云，自动填写服务地址和模型，只需配置 SecretId、SecretKey；硅基流动只需 API Key。各供应商凭据独立保存在 IDEA 密码保险箱。
- 插件设置页提供常驻的“语音输入 → 配置与测试”，可随时修改配置并录音测试。测试使用当前表单，识别结果只显示在配置窗口。
- 设置页显示已保存的当前供应商，保存切换后立即更新；录音浮层显示本次录音使用的供应商名称，不占用输入区空间，不显示模型名。
- 支持波形、录音时长、取消和识别状态。腾讯云单次最多 60 秒，其他服务最多 120 秒；取消、切换会话或离开聊天页时丢弃本次结果。
- Codex 每轮文件变更支持文件清单、增删行数和展开 diff，历史恢复保留最新变更快照。
- 回复和 diff 中的项目文件引用可在 IDEA 中打开，并定位到行。

语音识别需要单独配置服务，并允许 IDEA 使用麦克风。停止识别后音频直接发送到所选服务，详见[隐私说明](https://github.com/zhuxian89/idea-ai-agent/blob/main/PRIVACY.md)。建议先使用腾讯云；腾讯云一句话识别每月免费 5,000 次成功调用，硅基流动 SenseVoiceSmall 当前免费，实际额度、限流和超额收费以各服务官方规则为准。
