# 0.1.13 — 会话状态、交互选择与设置持久化

- 修复 IDEA 原生新会话、历史和设置按钮无响应，以及重复显示网页工具栏的问题；刷新和重连后保持正常。
- 修复发送或追加消息后，输入栏显示其他会话的 Agent/模型；实际请求保留用户刚选择的模型和执行权限。
- 补齐 Codex 异步选择题：暂停对应会话、展示选择卡片，用户明确提交答案后继续。取消、未作答和不完整答案不会自动代选。
- 语言与外观选择保存到 IDEA 持久化配置；重新安装插件后保留已保存的选择。
- 活动栏在切换会话后保留“最近更新于”和运行状态；耗时按秒、分秒、时分秒显示，已完成的会话不会因重放旧事件再次显示生成中。
- 包含此前本地版本的 Agent 管理、文件粘贴、执行权限选择、消息与排队同步改进。Codex/Claude Code 默认最高权限，用户可以在输入栏切换其他权限。
- Claude 计划模式保留只读工具与退出计划的确认，附加 CLI 参数不能覆盖界面选择的权限。

在 IDEA 的 Settings → Plugins → 齿轮 → Install Plugin from Disk 选择对应 ZIP，安装后重启 IDEA。支持 IDEA 2024.1、2024.2、2024.3；Mac 要求 macOS 12+。校验值随 Release 的 `SHA256SUMS.txt` 提供。

回归使用受控 Agent 协议和 HTTP/WebSocket，不调用付费模型。Windows 包在 Mac 上交叉编译；安装后的真实 Windows/IDEA/JCEF 操作仍需实机确认。详细验证记录见 [validation.md](../validation.md)。
