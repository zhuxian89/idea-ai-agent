# 0.1.5 — 本地测试草稿，未发布

按已确认的设计，将插件收敛为 Agent 配置与安装、聊天、聊天历史三个视图，共用同一个工具窗口。

- 移除项目列表、任务看板和独立的 Files / Git / Worktrees / Related files 面板及无关管理菜单。
- 顶部提供新会话、聊天历史、配置与安装入口；切换页面保留聊天草稿。
- 配置页直接展示识别状态、版本、配置、安装更新和重启，保留外观与语言。
- 聊天输入区增大，显示 Agent 与模型名称，原有权限、推理强度等选项继续由原组件提供。
- 安装输出和活跃聊天在主区域展示；历史会话继续复用原有加载、搜索、导入及续聊逻辑。
- 保留回复下方的复制、分叉、模型、推理强度、时间、耗时、上下文占用，并改善窄窗口换行与可读性。输入/输出 Token 与缓存命中率明细尚未接入。

本次调整界面和操作入口，复用已有配置表单、安装命令、会话与原生交互链路。另修复安装入口早于项目初始化的问题，补充 Mac 安装目录查找，并让配置页刷新立即检查 CLI 是否安装。Agent 执行适配器和 SDK 保持不变。

IDEA 的 Settings → Plugins → 齿轮 → Install Plugin from Disk，选择 ZIP 后重启 IDEA。兼容 IDEA 2024.1、2024.2、2024.3。Mac 包要求 macOS 12+，使用对应架构的 IDEA。

浏览器检查使用受控 Agent/历史接口及无害的 echo 命令，不执行真实安装、配置写入或模型调用。Mac 包为交叉编译产物，仍需 Mac 实机验证。

安装入口核对：[Codex 官方文档](https://learn.chatgpt.com/docs/codex/cli)、[Claude Code 官方文档](https://code.claude.com/docs/en/setup)。
