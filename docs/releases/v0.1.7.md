# 0.1.7 — 本地测试版，未发布

- Agent / 模型旁增加执行权限选择。插件中 Codex 和 Claude Code 默认最高权限；已有会话明确保存的权限继续保留，也可手动切回普通权限。修改从下一条消息生效，切换模型不会重置权限。
- Codex 使用原生 `danger-full-access` 与 `never`；普通模式使用 `workspace-write` 与 `on-request`。Claude 使用原生 `bypassPermissions`，普通模式使用 `default`。后端沿用原有会话 `mode` 字段与原生控制接口。
- 修正 Claude Go SDK 将“允许切换最高权限”错误映射为“启动即跳过权限”的参数问题，确保选择普通权限时不会被该标志覆盖。
- 原生方案选择、用户回答和计划模式保留；计划模式不会因为选择最高权限而自动关闭。
- 输入框粘贴现在接收普通文件和图片，并展示附件。此前只接收图片类型。浏览器测试覆盖普通文本文件的粘贴与移除；Mac Finder、IDE 项目树的系统剪贴板还需实机确认。

按用户要求暂不处理启动时短暂的白色区域。未增加项目列表或任务看板。

安装包在 `build/local-packages/`，提供 Windows x64、Mac Apple Silicon、Mac Intel。
继续使用 IDEA 2024.1 基线。Mac 包为交叉编译产物，真实 IDEA/JCEF 与已登录 Agent 的运行需本机测试。
测试详情见 [validation.md](../validation.md)。本次没有创建 GitHub Release。
