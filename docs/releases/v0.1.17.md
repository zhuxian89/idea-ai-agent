# 0.1.17 — 原生交互与事件可靠性修复

接通 Codex / Claude Code 的更多原生交互，修复 Codex 高频输出时可能漏掉请求和完成事件的问题。

- MCP 表单与 URL 确认：支持明确接受、拒绝、取消；表单校验失败后可以修改重试，数字和布尔值保留原始类型，复杂结构可用 JSON 填写。
- Codex 额外权限：展示请求范围，选择仅本轮、本会话或拒绝；不会批准请求以外的权限。
- Claude Code 已知原生对话框：支持备用模型重试、修改提示词和取消；未知对话类型按协议取消。
- Codex 事件可靠性：慢消费者不再导致 256 条缓冲满后静默丢事件；启动回合前即订阅，保留早于启动响应的事件。补齐原生请求去重和取消处理。
- 移除聊天输入区的 worktree 创建入口，在当前项目中工作。
