# 0.1.2 — 保留原生 Agent 行为

- 修复 Codex 推理档位被降级、Claude 默认模型及新会话缓存覆盖本机配置的问题。
- Claude 加载 `user,project,local` 配置，并完整传递附加 CLI 参数。
- 继承 CLI 权限；原生授权请求和方案选择等待用户答复。答案经后端接受才显示提交成功，支持失败提示及重试，修复重复提交与取消等待。
- 恢复 Git 项目的会话/任务 worktree；编辑器上下文完整传递，不再截断到 128000 字符。

本版本提供以下安装包，每个平台的同一份 ZIP 覆盖 IDEA 2024.1、2024.2、2024.3。插件 JAR 已通过社区版和旗舰版六个目标的兼容检查。业务项目可以使用 JDK 8，插件使用 IDEA 自带运行环境，无需另装开发 SDK。

| 系统 / 架构 | 下载 |
| --- | --- |
| Windows x64 | [idea-ai-agent-0.1.2-windows-amd64.zip](https://github.com/zhuxian89/idea-ai-agent/releases/download/v0.1.2/idea-ai-agent-0.1.2-windows-amd64.zip) |
| Mac，Apple 芯片（M 系列） | [idea-ai-agent-0.1.2-macos-arm64.zip](https://github.com/zhuxian89/idea-ai-agent/releases/download/v0.1.2/idea-ai-agent-0.1.2-macos-arm64.zip) |
| Mac，Intel 处理器 | [idea-ai-agent-0.1.2-macos-amd64.zip](https://github.com/zhuxian89/idea-ai-agent/releases/download/v0.1.2/idea-ai-agent-0.1.2-macos-amd64.zip) |

Mac 要求 macOS 12 或更新版本，请使用对应架构的 IDEA。下载 ZIP 后，在 IDEA 的 Settings → Plugins → 齿轮 → Install Plugin from Disk 安装，无需解压。需要本机安装并登录 Codex CLI 或 Claude Code。所有 ZIP 的 SHA-256 见附件 `SHA256SUMS.txt`。

两个 Mac 包从同一 v0.1.2 提交交叉编译，已校验 Mach-O 架构、版本和文件完整性；插件 JAR、前端及配置与 Windows 包完全一致。当前尚未在 Mac 实机验证 IDEA 启动及 Agent 执行。

问题清单、测试及尚未实机验证的边界见仓库的 `docs/native-agent-compatibility.md` 和 `docs/validation.md`。本次修复不宣称与所有 CLI 版本的全部终端交互 100% 对等。
