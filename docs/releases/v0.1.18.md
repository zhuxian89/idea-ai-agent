# 0.1.18 — 输入区显示思考强度

输入区的 Agent 选择器现在会持续显示当前模型的思考强度，切换后立即更新，避免开始新一轮对话前无法确认实际设置。

- Agent、模型和思考强度在同一个选择器中展示。
- 中英文分别使用“思考强度”和“Reasoning effort”，紧凑标签适配窄工具窗口。
- 仅在模型支持思考强度时展示该字段；不支持时保持原有布局。
- 补充 320、375、400 和 812 像素宽度下的交互与可见性验证。
- 补充 JetBrains Marketplace 英文介绍、更新说明、插件图标、隐私说明及兼容范围。
