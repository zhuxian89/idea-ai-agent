# 0.1.15 — 模型自动识别与聊天布局修复

修复重装或启动后 Agent 一直显示 `probe pending`、需要手动重启才能看到模型的问题，同时让错误状态和操作入口直接可见。

- 启动时自动识别已安装 Agent 的模型和运行选项；Windows 恢复自动探测，保留原有隐藏控制台窗口设置。
- 等待时显示“正在识别模型”；识别完成、连接恢复或收到更新后，模型列表自动刷新。
- 移除不易理解的问号。Agent 名称下直接展示状态和错误摘要，使用“查看详情”“重启 Agent”文字按钮；当前选中 Agent 的错误默认展开，恢复后自动显示模型选项。
- 用户消息重新贴齐聊天内容区右侧，保留正常边距；短文本、长文本、图片及消息操作栏对齐一致，助手正文继续靠左。
- 保留工具活动的默认折叠、分组和“已等待”“最近更新于”两项计时。

在 IDEA 的 Settings → Plugins → 齿轮 → Install Plugin from Disk 选择对应 ZIP，安装后重启 IDEA。兼容目标保持 IDEA 2024.1、2024.2、2024.3，最低 build 241；Mac 要求 macOS 12+。Release 附带 `SHA256SUMS.txt`。

本次改动已通过相关 Go 测试、TypeScript 检查和 Chrome 浏览器回归，覆盖模型自动刷新、明确状态入口、窄侧栏、中英文、工具分组以及 Codex/Claude 消息对齐。修复前的浏览器回归确认了旧请求返回过期模型状态及消息停在约 80% 宽度的问题。验证记录见 [docs/validation.md](../validation.md)。

Windows 安装包在 Mac 上交叉编译，未做 Windows 实机安装验证；Chrome 回归不替代 IDEA/JCEF 实机验收。0.1.14 所记录的 Claude 原生请求和 F7 剩余验收范围继续保留，本版未重新执行真实模型请求。
