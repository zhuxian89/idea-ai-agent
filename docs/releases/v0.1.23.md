# 0.1.23 — 每轮文件变更与 IDEA 原生 Diff

本版本把“这轮对话改了什么”变成可直接审查的工作流，同时继续保持 Agent 原生会话、工具、提示词、权限和配置不变。

- 每轮对话结束后展示修改文件清单和 `+/-` 统计，可展开查看 inline diff；文件行右侧提供“在 IDEA 中打开”和“在 IDEA 中对比”两个直达按钮。
- 支持打开 IDEA 原生左右 Diff 弹窗：本轮修改使用回合前快照对比当前结果；关联文件使用 Git `HEAD` 对比当前工作区。
- Turn diff 对 Codex CLI、Claude Code 和兼容 ACP Agent 共用同一会话旁路采集；命令执行、补丁执行器、原生 diff 事件混合的修改也能进入清单。
- 采集前恢复本轮开始时已修改文件的基线，避免把对话前已有修改误报为本轮修改；已有修改、staged、未跟踪、新增、删除、重命名、二进制和 CRLF 均有回归覆盖。
- Windows 盘符路径、文件行号引用和 Markdown 链接可在 IDEA 中直接打开，不再触发页面刷新或新会话。
- 用户消息摘要按钮移动到会话标题栏右上角，移除输入区上方的 Codex 周限 / 重置指示，避免与文件统计和输入操作互相遮挡。
- 兼容 IntelliJ IDEA 2024.1 及更高版本，并增加 IDEA 2026.3 EAP Plugin Verifier 覆盖。

最低支持 IntelliJ IDEA 2024.1，不设置最高版本限制；macOS 12+。本次提供 4 个平台安装包和 1 个 Marketplace 通用包，另附 `SHA256SUMS.txt`。
