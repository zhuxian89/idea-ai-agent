# Local AI Agent v0.1.1

在 IntelliJ IDEA 中使用本机 Codex、Claude Code 和 MindFS 已支持的 Agent。复用 MindFS 的会话、流式工具调用、模型配置、历史记录、任务看板与 Git 界面，并接入 IDEA 编辑器上下文和文件跳转。

## 下载与安装

下载本 Release 的 `idea-ai-agent-0.1.1-windows-amd64.zip`，适用于 Windows x64。不要选择 GitHub 自动生成的 Source code 压缩包。

在 IDEA 中打开 **Settings → Plugins → 齿轮 → Install Plugin from Disk**，选择下载的 ZIP。安装后打开项目和右侧 **AI Agent** 工具窗口。

- 同一份 ZIP 支持 IDEA **2024.1、2024.2、2024.3**，社区版和旗舰版均通过 JetBrains Plugin Verifier 检查。
- 使用 IDEA 自带且包含 JCEF 的运行环境；业务项目可以继续使用 **JDK 8**，不需要为插件另装开发 SDK、Go 或 Gradle。
- 至少安装并配置 Codex、Claude Code 等一个本地 Agent CLI。Agent 使用其现有的登录与模型配置。

## 验证范围

构建、JUnit 测试、IDEA 2024.1 自带 Java 17 环境测试及六个 IDEA 目标的 API 兼容检查通过。打包的本地服务和前端已完成 HTTP 与 Chrome 浏览器冒烟验证。

真实 IDEA JCEF 窗口联调、已登录 Agent 的实际代码修改流程尚未完成验证。当前附件仅提供 Windows x64，macOS 与 Linux 包尚未提供。

项目基于 MindFS，按 GNU AGPL v3 分发。完整源码、来源说明和验证记录随仓库提供。
