# Local AI Agent 0.1.26

多个 IDEA 项目现在可以共用一台电脑的远程入口，使用浏览器或手机切换各自开放的项目。每个项目保留原有 Agent 后台和会话；手机扫码或打开访问链接即可自动授权，无需输入配对码。

- 在远程访问管理中单独开放或暂停项目，也可以关闭整台电脑的远程入口。
- 保留会话位置和项目文字草稿；切换项目时提醒处理未保存的文件编辑。
- 插件升级时自动更新共享远程后台，保留电脑身份并重新登记项目。
- 默认使用 `https://relay.20260310.best`；已有绑定如果属于其他 Relay，切换服务后需要重新绑定。

安装时根据系统选择 Windows x64、Windows ARM64、macOS Apple Silicon 或 macOS Intel 包；JetBrains Marketplace 通用包包含四种运行时。使用远程项目时需要保持电脑联网并在 IDEA 中打开对应项目。

Projects on one computer can now share a remote entry. Switch among individually enabled IDEA projects from a browser or phone, authorize via QR code or access link, and continue using each project's existing Agent backend and sessions. The shared host upgrades automatically and preserves its computer identity.
