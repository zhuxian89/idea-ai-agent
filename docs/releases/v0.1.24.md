# 0.1.24 — 实时 Agent 细节与桌面工作流完善

- 状态区域固定两行：表情与具体活动在第一行，等待时长和最近更新时间在第二行。优先显示原生工具说明、文件或搜索目标，其次显示明确进行中的计划；不猜测、不额外调用模型。
- Run/Debug 控制台选区可选择“交给当前会话分析”或“在新会话中分析”，保留原会话草稿与附件，不自动发送。
- 支持主动刷新 Agent/模型列表，无须重启 IDEA。
- 修复窄侧栏和中文输入法场景的 Enter 发送、已回答仍显示等待的问题；断网时显示连接状态并提供手动恢复操作。
- 修复旧任务数据库缺少 `template_snapshot_json` 的启动错误，幂等补列并保留原有数据。

构建命令：`node scripts/package-plugin.mjs release`。

五个 ZIP 和 `SHA256SUMS.txt` 位于 `build/releases/0.1.24/`：

- `idea-ai-agent-0.1.24-windows-amd64.zip` — Windows x64。
- `idea-ai-agent-0.1.24-windows-arm64.zip` — Windows ARM64。
- `idea-ai-agent-0.1.24-macos-arm64.zip` — Mac Apple 芯片。
- `idea-ai-agent-0.1.24-macos-amd64.zip` — Mac Intel。
- `idea-ai-agent-0.1.24.zip` — 包含四种运行程序的通用包，可用于 Marketplace 上传。

IDEA 设置 → 插件 → 齿轮 → 从磁盘安装，选择 ZIP，无须解压。构建安装包和 push 源码不等于已发布 GitHub Release 或上传 Marketplace。
