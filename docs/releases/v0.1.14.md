# 0.1.14 — 简洁工具活动与历史一致性

Codex 和 Claude Code 共用的工具过程默认显示为轻量摘要行，点击后查看完整详情。进展文字与最终回答保持独立，工具密集的对话更容易阅读。

- 同一轮中连续完成的普通操作可收成数量摘要，展开后逐项查看；正在运行、失败、审批、提问、文件修改和子任务保持可见。
- 应用内切换会话时保留主动展开/收起选择。详情按需加载，持续输出时保留用户阅读位置，复制使用完整原文。
- 读取、搜索、命令和 MCP 操作使用共用的中英文摘要，原生终态与可用耗时在实时和历史中保留。
- 保留底部“已等待”和“最近更新于”两项计时，以及用户直接执行 shell 的默认展开行为。
- 修复 Codex 0.154 的实时命令与历史 `exec` 包装重复显示，以及包装完成掩盖内层非零退出码的问题。

验证范围：前端 145 项基线与 4 项就绪检查通过，包含 16 组宽度/主题/缩放组合、1000 条活动和 1 MiB 连续日志；相关 Go 测试、21 项 Kotlin 测试、TypeScript、构建和完整应用冒烟通过。真实 Codex 0.154 已验证成功/失败命令、完整历史同步、默认折叠和详情读取。Plugin Verifier 对当前 0.1.14 的 IC 2024.1 返回 Compatible；其余 IDEA 目标本次未重新跑兼容检查。

尚未完成：Claude Code 2.1.270 实际请求 180 秒内未返回终态；IDEA/JCEF 的主题、缩放、键盘、剪贴板和滚动仍缺完整实机验收。Windows 包在 Mac 交叉编译，未做 Windows 实机安装验证。同轮已保存实时命令时，历史执行包装不再重复插入；缺少可靠内层调用 ID 的包装记录不能用于补齐该轮漏失的内层命令。本次发布已完成的功能，F7 整体验收继续保留未完成状态。
