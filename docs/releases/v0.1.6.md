# 0.1.6 — 本地测试版，未发布

修复 Claude Code 在插件中报 `invalid configuration for Model: model must be specified`。
错误发生在第三方 Go SDK 的客户端构造阶段，尚未启动用户的 Claude CLI。
保留原固定版本 SDK，做一处校验修复，使不指定模型时沿用 CLI 配置。
没有固定替代模型或放宽权限校验。补充的回归测试覆盖真实客户端构造器及启动参数，
弥补原测试只检查选项和传输层的遗漏。

- 新会话、聊天历史、Agent 配置与安装三个图标显示页面内悬停提示，键盘聚焦也可查看，Esc 可关闭。
- 聊天历史、Agent 配置支持再次点击收回，输入草稿继续保留。
- Agent / 模型弹窗固定两列宽度，折叠模型列表或切换错误详情不再左右移动；缩放工具窗口时重新定位，避免被输入区遮挡。
- 模型列表保留“默认模型”入口；弹窗使用插件主题颜色。
- 加入当前代码、重新连接改为 IDEA 工具窗口标题栏的原生操作按钮，带名称及说明。

安装包在 `build/local-packages/`，包含 Windows x64、Mac Apple Silicon 和 Mac Intel。
验证结果见 [validation.md](../validation.md)。Mac 包为交叉编译产物，实际 Mac 上的
Claude 登录、聊天与 IDEA 原生工具栏外观仍需本地测试。
