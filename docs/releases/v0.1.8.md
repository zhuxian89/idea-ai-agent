# 0.1.8 — 消息同步与等待状态，本地测试版

- 修复并发发送队列快照时，较旧的快照把已经出队的消息重新显示为排队的问题。队列通知按会话顺序发布，并在发布时读取当前状态。
- 重连时明确同步空队列，清除页面里过期的排队条目，避免它们让已结束的会话继续显示等待。
- 正式开始执行的用户消息也回传给发送窗口。即使页面误以为消息仍需排队，也能显示服务端实际接收并开始的消息；重放仍按已有规则去重。
- 等待区根据实际消息和工具事件显示等待 Agent、思考、工具执行、等待用户回答及断线重连。显示已等待时间和最近更新间隔，60 秒没有新事件时提示暂无进展，不据此判定模型卡死或自动重发、取消请求。

保留 0.1.7 的原生权限选择和文件粘贴修复。没有调整 Codex / Claude Code 的模型执行逻辑、计划模式或权限策略。

验证记录见 [validation.md](../validation.md)。安装包用于本地测试，未创建 GitHub Release。
