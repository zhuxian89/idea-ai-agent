# 0.1.25 — IDEA、浏览器、手机三端远程访问

- 远程访问入口与 Relay 绑定：无需额外安装 MindFS，三端共用同一项目后台服务和会话，实时同步消息与执行进度。
- 手机扫码自动配对；电脑首次通过普通链接访问时输入配对密钥，以后自动记住。
- 已开启远程访问的项目随 IDEA 打开自动上线，不再依赖打开插件面板。
- 浏览器可查看和编辑磁盘文件，保存时检测版本冲突，页面内切换文件保留编辑草稿。
- 网络连接失败保留有效配对信息，显示真实错误并提供手动重试。
- 修复多端连续发送时轮次完成通知的顺序，以及完成状态回放与排队消息的交接。
- 更新中英文市场描述、入门说明和隐私说明。

远程访问为可选功能；使用时电脑需要联网，IDEA 和对应项目需要保持运行。不支持关闭 IDEA 后继续远程访问，也不传输尚未保存的 IDEA 编辑器缓冲区。

## 安装包

`build/releases/0.1.25/` 包含 Windows x64、Windows ARM64、macOS Apple Silicon、macOS Intel 四个独立 ZIP，以及 Marketplace 通用 ZIP 和 `SHA256SUMS.txt`。
