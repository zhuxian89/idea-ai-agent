# 0.1.16 — 当前文件入口与回复信息修复

输入框上方新增「加入当前文件」，把当前激活编辑器标签页的文件路径加入正在使用的 Agent 对话；回复信息栏补回思考强度和 Context 上下文占用。

- 打开多个文件时，加入的是当前正在查看的文件路径。项目文件树和文件标签页右键提供「加入 AI Agent 对话」，可直接加入右击文件。
- 保留「加入当前代码」的选中片段和未保存内容功能；加入文件路径时保留当前会话与草稿，不自动发送消息。
- 回复展示实际记录的思考强度与 `Context 42% (109K/258K)` 等信息。Context 按每条回复保存，重新打开、缓存恢复与离线查看时保持各轮数值。
- 已有 Codex 历史从本机原生记录补回缺失信息；缺少原始数据时显示“未提供”。共用保存与展示同时适用于 Claude 已提供的数据。
- 保留工具默认折叠、耗时、“已等待”和“最近更新于”。窄侧栏自动换行，适配中英文与深浅色主题。
- 输入/输出 Token 和缓存命中率明细暂缓实现。
