# 0.1.19 — 支持 IDEA 2024.1 及更高版本

修正插件兼容范围：IntelliJ IDEA 2024.1 是最低版本，不再设置最高版本限制。IDEA 2024.1 以及所有更高版本均可安装插件。

- 插件描述只保留 `since-build="241"`，不生成 `until-build`。
- Marketplace 将不会再把 IDEA 2025.x、2026.x 或未来版本排除在安装范围外。
- 继续包含 0.1.18 的输入区思考强度显示、Marketplace 英文介绍、插件图标和隐私说明。
- IDEA 2024.1、2024.2、2024.3 的社区版和旗舰版 Plugin Verifier 检查保持通过。

| 平台 | 下载 |
| --- | --- |
| Mac，Apple 芯片（M 系列） | [macos-arm64.zip](https://github.com/zhuxian89/idea-ai-agent/releases/download/v0.1.19/idea-ai-agent-0.1.19-macos-arm64.zip) |
| Windows x64 | [windows-amd64.zip](https://github.com/zhuxian89/idea-ai-agent/releases/download/v0.1.19/idea-ai-agent-0.1.19-windows-amd64.zip) |

在 IDEA 的 Settings → Plugins → 齿轮 → Install Plugin from Disk 选择对应 ZIP，安装后重启 IDEA。最低支持 IntelliJ IDEA 2024.1，不限制更高版本；Mac 要求 macOS 12+。Release 附带 `SHA256SUMS.txt`。
