# 0.1.21 — 修复 Windows 插件更新锁定

修复 Windows 上旧版本本地服务仍在运行时，IDEA 更新插件可能因 `AccessDeniedException` 失败的问题。

- 将当前平台的本地运行时复制到 IDEA system cache 的内容哈希目录后再启动，不再直接运行插件安装目录中的可执行文件。
- 插件卸载或 IDEA 退出前同步停止所有活动的本地服务，并等待可执行文件解除占用。
- 多个项目或 IDEA 窗口同时启动时，通过完整内容哈希、临时目录和原子移动安全复用同一份缓存。
- 通用 Marketplace ZIP 继续包含 Windows x64、Windows ARM64、macOS Apple Silicon 和 macOS Intel 四种运行程序。
- 最低支持 IntelliJ IDEA 2024.1，不设置最高版本限制。
