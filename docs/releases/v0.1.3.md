# 0.1.3 — 修复 macOS 已安装 CLI 无法识别

Mac 从 Dock/Finder 启动 IDEA 后，即使终端能找到 Codex 和 Claude Code，插件也可能显示空 Agent 列表。原因是旧启动器直接使用 IDEA 进程的原始环境，遗漏了 IDEA 从用户 shell 恢复的 `PATH`。

本版让本地服务、CLI 检测和实际执行使用 IDEA 恢复的完整终端环境，支持用户自定义安装位置，包括 `~/.hermes/node/bin` 和 `~/.local/bin`。保留原生 CLI 的模型、权限、登录及配置行为；无需重新安装 CLI。

| 系统 / 架构 | 下载 |
| --- | --- |
| Windows x64 | [idea-ai-agent-0.1.3-windows-amd64.zip](https://github.com/zhuxian89/idea-ai-agent/releases/download/v0.1.3/idea-ai-agent-0.1.3-windows-amd64.zip) |
| Mac，Apple 芯片（M 系列） | [idea-ai-agent-0.1.3-macos-arm64.zip](https://github.com/zhuxian89/idea-ai-agent/releases/download/v0.1.3/idea-ai-agent-0.1.3-macos-arm64.zip) |
| Mac，Intel 处理器 | [idea-ai-agent-0.1.3-macos-amd64.zip](https://github.com/zhuxian89/idea-ai-agent/releases/download/v0.1.3/idea-ai-agent-0.1.3-macos-amd64.zip) |

在 IDEA 的 Settings → Plugins → 齿轮 → Install Plugin from Disk 中选择对应 ZIP，然后完全退出并重新启动 IDEA。Mac 要求 macOS 12+，请使用对应架构的 IDEA。继续使用 IDEA 2024.1、2024.2、2024.3，业务项目可使用 JDK 8，无需为插件另装开发 SDK。

回归测试模拟 IDEA 的终端环境，实际启动子进程查找 Codex、Claude 和 Node 替身；不调用模型。Mac 包为交叉编译产物，尚未在 Mac 实机验证此次修复。验证详情见仓库的 `docs/validation.md`，各 ZIP 校验值见附件 `SHA256SUMS.txt`。
