Start in IDEA

  1. Install and sign in to Codex CLI or Claude Code. If it already works in your terminal, the plugin reuses its configuration.
  2. Open a project in IntelliJ IDEA and open the AI Agent tool window.
  3. Choose an Agent and send a message. Use History to resume sessions, and inspect file changes in IDEA.

Continue from a browser or phone

  1. Choose Remote access in the plugin toolbar, sign in to Relay and connect the computer. Enable each project you want to access.
  2. Scan the QR code with your phone, or open the access link on another computer, to connect automatically without entering a pairing code.
  3. Keep the computer online and the IDEA project running. Enabled projects reconnect when opened in IDEA without opening the panel.

The clients share messages, progress and the same Agent backend. You can respond to questions and approvals and edit text files in the browser. Unsaved IDEA editor buffers are not synchronized. Treat the QR code and access link as credentials and do not forward them. A failed connection can be retried with saved authorization.

Optional voice input

Configure a speech provider in Settings, then use the microphone to transcribe speech into an editable draft. Transcription does not send a message automatically. See the Privacy Notice for remote-access and speech-provider data handling.

先在 IDEA 中开始

  1. 安装并登录 Codex CLI 或 Claude Code。本机终端已经可用时，插件直接复用其配置。
  2. 在 IntelliJ IDEA 中打开项目，再打开 AI Agent 工具窗口。
  3. 选择 Agent 并发送消息；从历史中恢复会话，在 IDEA 中查看文件修改。

在浏览器和手机继续

  1. 点击插件工具栏的“远程访问”，登录 Relay 并连接电脑，然后分别开放需要远程访问的项目。
  2. 手机扫描二维码，或在其他电脑打开访问链接，即可自动连接，无需输入配对码。
  3. 保持电脑联网及 IDEA 项目运行。已开启远程访问的项目随 IDEA 打开自动上线，无需打开插件面板。

三端共用消息、进度和 Agent 后台服务，可远程回答问题、处理审批及编辑文本文件；不会同步 IDEA 中尚未保存的编辑器内容。二维码和访问链接均携带访问权限，请勿转发。连接失败可直接重试，保留有效授权。

可选语音输入

在设置中配置语音供应商，再使用麦克风将录音转成可编辑草稿，不会自动发送。远程访问与语音服务的数据处理方式见隐私说明。
