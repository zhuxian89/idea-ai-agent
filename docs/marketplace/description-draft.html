Native Codex CLI and Claude Code in IntelliJ IDEA. Speak your request, add context, and review each turn in IDEA's native Diff.

Local AI Agent connects your project to the coding agents installed on your machine. If your CLI already works, reuse its login, model configuration, project instructions and MCP setup—without configuring them again in the plugin.

Your agent's native workflow

Continue native sessions, follow streaming replies and tool activity, and handle permission prompts, Plan Mode and follow-up questions inside IDEA. Agent-specific capabilities depend on the selected CLI. Switch between open conversations with tabs and search your project conversation history.

Speak, attach, then send

Voice input inserts recognized text into your draft. Edit it before sending; recording never sends a message automatically. Attach files or images, or add selected code and project files as context. Supported attachment handling depends on the agent and model.

Fixed turn snapshots. IDEA's own Diff.

Keep the files-changed panel compact until you need it. Expand a turn's changes, inspect the inline diff, or open IDEA's native side-by-side comparison. Saved before/after snapshots preserve that turn's comparison even if the working file changes later. Workspace-based tracking can include concurrent manual edits; incomplete captures are marked in the UI.

Local integration, your providers

The bundled service listens only on a random 127.0.0.1 port. Conversation data and plugin settings stay on your machine. Agent requests follow the CLI's configuration and provider terms. Optional voice input sends recordings directly to the speech provider you choose; speech credentials are stored in the IDE Password Safe.

Getting started: select an agent. If it is missing, use the installation shortcut or official instructions. Complete the agent's login/configuration externally; CC Switch is an optional configuration tool. Return to the plugin and test the connection. The plugin does not add a separate agent account or provider configuration system.

Requirements: IntelliJ IDEA 2024.1+ with JCEF and a configured, authenticated supported Agent CLI. Windows x64/ARM64 and macOS Apple Silicon/Intel. Voice input requires a supported speech service and your own credentials.

中文

原生 Codex CLI 与 Claude Code，就在 IntelliJ IDEA。语音提需求，附件补上下文，IDEA 原生 Diff 审查每轮修改。

Local AI Agent 将项目连接到本机安装的 Coding Agent。本机 CLI 已可用时，沿用它的登录、模型配置、项目指令和 MCP，无需在插件里再配置一遍。

保留 Agent 原生工作方式

继续原生会话，查看流式回复与工具活动，在 IDEA 中处理权限请求、Plan Mode 与追问。具体能力取决于所选 CLI。通过标签页切换打开的会话，在历史页搜索项目对话。

说出需求，附上文件，确认后发送

语音识别文字进入草稿，可以编辑，不会自动发送。支持添加文件、图片、选中代码和项目文件作为上下文；具体附件处理能力取决于 Agent 与模型。

固定回合快照，IDEA 原生 Diff

本轮修改文件默认折叠，需要时再展开。可查看行内差异，也可直接打开 IDEA 原生左右对比。保存的前后快照保留该回合的比较结果，不会随之后的工作文件编辑而改变。基于工作区的追踪可能包含同期手动修改；不完整的捕获会在界面中标注。

本机集成，服务由你选择

内置服务仅监听随机 127.0.0.1 端口，会话数据与插件设置保存在本机。Agent 请求遵循 CLI 自身的配置和供应商条款。可选语音输入把录音直接发送给你选择的语音供应商，语音凭据保存在 IDEA 密码保险箱。

首次使用：选择 Agent，未安装时使用快捷安装或官方安装说明。在插件外完成 Agent 登录与配置，也可使用 CC Switch 管理配置，再回到插件测试连接。插件不另建 Agent 账号或供应商配置体系。

运行要求：IntelliJ IDEA 2024.1+ 且带有 JCEF，至少一个已配置并登录的受支持 Agent CLI。支持 Windows x64/ARM64 与 macOS Apple Silicon/Intel。语音需要受支持的语音服务及自己的凭据。
