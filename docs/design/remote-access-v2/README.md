## 方向

日常只呈现扫码、打开浏览器、复制链接。二维码与复制的连接链接携带相同的电脑配对凭据，通过 URL fragment 交给浏览器，复用现有二维码自动配对能力。链接含访问权限，明确提示不要公开分享；普通节点 URL 仍需授权，不能绕过验证。不增加“回到 IDEA 点击批准”的日常障碍。

首次点击“开启远程访问”进入现有访问服务的登录绑定确认，完成后自动回到可用状态；中断时给“继续连接”。已有绑定的电脑，新项目只需主动加入。旧版本迁移保留数据及既有权限边界，不把原项目密钥静默扩大成全部项目权限。

管理界面集中控制项目开放范围及整机远程开关。手机扫码直达当前项目的当前对话；切换项目在顶栏完成。当前会话定位与连接链接收藏恢复属于待实现细节，需要在实施方案中确认。

异常分别描述电脑离线、项目关闭、服务失败，提供对应操作，不能把“无法连接”伪装成仍在执行。
