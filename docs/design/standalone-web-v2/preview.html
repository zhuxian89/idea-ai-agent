设计说明

网页右栏按项目目录列出会话卡片。点对话顶部左右两端的侧栏图标，可以收起或展开对应的栏；图标里的竖栏有填充表示该栏已展开。手机用卡片浏览会话，点卡片进入对话，点左上角返回。输入栏的模式和 Agent 图标分别打开对应设置。

左栏只留文件树。Git 变更、工作树、关联文件放在左栏 ⋮ 菜单最上面的「项目工具」里，手机在项目页右上角的 ⋮。点网页会话栏的放大镜，可以按标题或消息内容查找。

手机聊天页没有底部导航：点标题弹出「切换会话」，其他会话在等你回答或失败时，顶部会出现提示条。等你回答时，点输入框上方那一行，在底部面板里查看命令并选择；命令超过 4 行会先折叠。

设备类型默认自动判断，识别错了可以在 ⋮ 菜单（手机在「更多」页）里手动指定为电脑、平板或手机。顶部的「电脑 / 平板 / 手机」只用来在设计稿里切换预览。要查看等待授权、离线等示例，打开「设计预览」里的模拟活动状态。

这是独立的交互设计预览，使用示例会话与数据，按钮不会发送真实消息或修改项目。
