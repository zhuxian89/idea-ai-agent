## 侧栏文字层级

项目名和主会话名统一为 13px、普通 500/选中 600 字重；项目分组和子代理名称为 12px，Agent 与时间等辅助信息为 11px。移除会话标题在窄屏缩至 11px 的规则。1600、1100、390px 三种宽度下主名称字号一致；中间区域所有元素的计算字号、字重、颜色、尺寸和坐标与调整前一致。浅色、深色截图已更新，记录见 `build/reports/remote-workspace-typography.json`。
