## 问题

公网页面发现新版本后只有一个“查看新版”链接，要回到电脑上敲命令才能更新。页面代码的注释写明“浏览器只能查看发布，安装由本机 IDEA 负责”，后台也没有给独立安装包接自更新接口。用手机或在外面打开公网页面的人看到新版本也点不了。

## 设计

- **有新版本**：版本行下面出现主按钮“立即更新”和次按钮“查看新版”，下面一行小字说明“更新会重启后台，进行中的会话会中断，聊天记录保留”。
- **确认弹窗**：点“立即更新”先确认。写明会中断正在运行的会话；聊天记录、端口和远程绑定保留；失败自动恢复到当前版本；更新期间页面会断开，恢复后自动重新连接。按钮是“取消”和“更新并重启”。
- **更新中**：转圈加进度条，文字“正在更新到 0.1.52…”。页面随后断开，显示“后台正在重启，页面会自动重新连接…”。
- **完成**：版本号变成新版本，绿色提示“已更新到 0.1.52，聊天记录已保留”。
- **失败**：红色提示“更新没有完成，已保留原来的 0.1.51”，可展开详情，按钮是“重试”和“查看新版”。
- 只有能登录这台电脑的人才看得到按钮，与其他设置一样受登录保护。

## 实现时的约定（尚未实现）

- 后台新增受保护的接口：触发更新、读取更新状态；同一时刻只允许一个更新在跑。
- 更新由脱离后台进程的安装脚本执行，因为安装过程要停掉后台本身。macOS、Linux 用固定在线入口；安装脚本已有“失败自动恢复原服务”。
- 脚本使用后台自己的环境变量，保证启动配置里的环境不变，不带入其他变量。
- Windows 要等在真实 Windows PowerShell 5.1 上验证后才开放，在此之前 Windows 页面仍只显示“查看新版”。
