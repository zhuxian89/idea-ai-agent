Native Codex CLI and Claude Code workflows in IntelliJ IDEA, with zero reconfiguration when your CLI already works.

Local AI Agent connects the current IDEA project directly to locally installed coding agents. It keeps native sessions, the tool loop, authentication, model settings, project instructions, MCP servers, permission prompts, Plan Mode, and follow-up questions in IDEA. There is no second API key, login, model, or MCP setup to recreate.

Native Agent capabilities

  • Stream replies, reasoning status, commands, file edits, MCP calls, and subagent activity.
  • Resume native CLI sessions and project-scoped conversation history.
  • Choose the Agent, model, reasoning effort, Plan Mode, and execution permission level.
  • Detect, configure, install, update, and restart supported local Agent CLIs from IDEA.

Voice input that stays in your draft

Click the microphone in the composer, speak, then stop recording to insert the recognized text at the draft cursor. Recording never sends a message automatically. Configure Tencent Cloud, SiliconFlow, or a compatible custom speech service with your own credentials; each provider's credentials are stored separately in the IDE Password Safe.

  • Add selected code, the current file, or a project-tree file to the draft without sending it.
  • Open project-file references and inspect the files changed by a Codex turn in IDEA.
  • Follow the IDEA light or dark theme and switch between English and Simplified Chinese.

Local by default: the bundled service listens only on a random 127.0.0.1 port. Conversations and plugin settings stay on the local machine. Requests made by an Agent CLI follow that CLI's own configuration and provider terms. Optional voice input sends recorded audio directly to the speech provider selected by the user.

Requirements: IntelliJ IDEA 2024.1 or later with JCEF, plus at least one supported Agent CLI that is configured and signed in. Windows x64/ARM64 and macOS Apple Silicon/Intel are supported.

中文

在 IntelliJ IDEA 中尽可能完整地还原 Codex CLI 和 Claude Code 的原生能力；本机 CLI 已可用时，安装后零配置接入。

Local AI Agent 将当前 IDEA 项目直接连接到本机安装的 Coding Agent。插件保留 Agent 原生的会话、 工具循环、登录状态、模型配置、项目指令、MCP、权限请求、Plan Mode 和追问交互；无需重复填写 API Key、再次登录或重新配置模型与 MCP。

原生 Agent 能力

  • 实时展示回复、推理状态、命令执行、文件修改、MCP 调用和子 Agent 活动。
  • 恢复原生 CLI 会话，并按项目保存和继续历史对话。
  • 选择 Agent、模型、思考强度、Plan Mode 和执行权限。
  • 在 IDEA 内检测、配置、安装、更新和重启本机 Agent CLI。

不自动发送的语音输入

点击输入框麦克风开始录音，停止后将识别文字插入原光标位置，不会自动发送消息。可使用腾讯云、 硅基流动或兼容的自定义语音服务；填写自己的凭据后，各供应商凭据分别保存在 IDEA 密码保险箱。

  • 把选中代码、当前文件或项目树中的文件加入输入框，不会自动发送。
  • 在 IDEA 中打开回复引用的项目文件，并查看 Codex 单轮修改的文件。
  • 跟随 IDEA 深色/浅色主题，界面支持简体中文和英文。

本机优先：插件内置服务仅监听随机的 127.0.0.1 端口；会话和插件设置保存在本机。 Agent CLI 发出的请求遵循该 CLI 自身的配置与服务条款。可选语音输入只会把录音直接发送给用户选择的 语音供应商。

运行要求：IntelliJ IDEA 2024.1 或更高版本并带有 JCEF；至少安装、配置并登录一个受支持的 Agent CLI。支持 Windows x64/ARM64 和 macOS Apple Silicon/Intel。
