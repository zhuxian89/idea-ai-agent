Getting started

  1. Install Local AI Agent from JetBrains Marketplace and restart IntelliJ IDEA if prompted.
  2. Make sure Codex CLI or Claude Code is installed, configured, and authenticated. If it already works in your terminal, open a project and select the AI Agent tool window on the right: no additional API key, login, model, or MCP configuration is required.
  3. Start a native Agent conversation. You may choose an Agent, model, reasoning effort, and execution permission; leaving them unchanged keeps the CLI defaults.
  4. Optional voice input: open Settings → Voice input → Configure and test, choose Tencent Cloud, SiliconFlow, or a compatible custom service, and enter your own credentials. Then click the microphone in the composer, speak, and choose Stop and transcribe. The recognized text is inserted into the draft and is never sent automatically.
  5. To add code, use Send to AI Agent from the editor context menu or press Ctrl+Alt+A. You can also add files from the project tree or editor tabs; this adds context to the draft without sending it.

Requires IntelliJ IDEA 2024.1 or later with JCEF. Voice recording requires the operating-system microphone permission for IDEA.

中文快速开始

  1. 从 JetBrains Marketplace 安装 Local AI Agent；如果 IDEA 提示，请重启。
  2. 确认 Codex CLI 或 Claude Code 已安装、配置并完成登录。若它已经能在终端中使用，打开项目后点击 IDEA 右侧的 AI Agent 工具窗口即可开始：无需再次填写 API Key、登录或重新配置模型与 MCP。
  3. 开始原生 Agent 对话。可选择 Agent、模型、思考强度和执行权限；不修改时继续使用 CLI 默认配置。
  4. 可选语音输入：打开 设置 → 语音输入 → 配置与测试，选择腾讯云、硅基流动或兼容的自定义服务，并填写自己的凭据。随后点击输入框麦克风录音，说完点击停止并转为文字；识别结果插入输入框，不会自动发送。
  5. 需要加入代码时，在编辑器右键选择发送到 AI Agent，或按 Ctrl+Alt+A；也可以从项目文件树或编辑器标签页加入文件。它们只加入输入框，不会自动发送。

要求 IntelliJ IDEA 2024.1 或更高版本，并使用包含 JCEF 的运行环境。语音录音首次使用时需要允许 IDEA 使用系统麦克风。
