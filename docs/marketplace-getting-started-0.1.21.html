Getting started

  1. Install Local AI Agent from JetBrains Marketplace and restart IntelliJ IDEA if prompted.
  2. Make sure Codex CLI or Claude Code is installed, configured, and authenticated. If it already works in your terminal, no additional API key, login, model, or MCP configuration is required.
  3. Open a project and select the AI Agent tool window on the right.
  4. Choose an Agent, model, reasoning effort, and execution permission, then start a conversation.
  5. To add code, use Send to AI Agent from the editor context menu or press Ctrl+Alt+A. You can also add files from the project tree or editor tabs.

Requires IntelliJ IDEA 2024.1 or later with JCEF.

中文快速开始

  1. 从 JetBrains Marketplace 安装 Local AI Agent；如果 IDEA 提示，请重启。
  2. 确认 Codex CLI 或 Claude Code 已安装、配置并完成登录。如果它已经能在终端中使用，无需再次填写 API Key、登录或重新配置模型与 MCP。
  3. 打开一个项目，然后点击 IDEA 右侧的 AI Agent 工具窗口。
  4. 选择 Agent、模型、思考强度和执行权限，然后开始对话。
  5. 需要加入代码时，在编辑器右键选择发送到 AI Agent，或按 Ctrl+Alt+A；也可以从项目文件树或编辑器标签页加入文件。

要求 IntelliJ IDEA 2024.1 或更高版本，并使用包含 JCEF 的运行环境。
