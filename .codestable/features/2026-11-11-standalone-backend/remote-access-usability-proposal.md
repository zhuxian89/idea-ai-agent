# 远程访问易用性调整方案

2026-11-12。状态：用户确认 [HTML 交互原型](../../../docs/design/remote-access-v3/preview.html) 后，生产界面与动态检查已实现并验证，尚未打包。依据当前 `RemoteAccessDialog`、`RemoteBackendChoice`、`StandaloneUpdatePanel` 及对应截图。

## 用户目标与现有问题

用户打开远程访问，是要在另一台设备继续使用项目。首页应说明当前是否可用、如何进入，以及关闭 IDEA 后是否仍可用。

当前页面把首次选择、安装与重启、日常扫码、项目管理、后台维护和版本升级放在一起。具体表现：

- “管理”和“设置”调用同一个页面，入口重复。
- “更改使用方式”与重启/停止服务常驻访问页，维护操作挤占使用入口。
- 已安装、服务运行、远程已连接分别展示，用户需要自己判断能否使用。
- 原生更新横幅在网页弹窗外，版本与提示重复占据聊天空间。
- “通过 Relay 打开此节点”、进程地址和日志路径出现在日常流程中。
- 升级目标写死在插件中，后台每次更新都要另发插件。

## 页面结构

保留现有弹窗、字体、颜色与交互习惯，只调整层级和状态，不增加桌面管理应用。

首页的已连接状态：

```text
远程访问                      已连接    ×

当前项目：Project A
从其他设备打开后，也可切换项目

                 二维码

         [打开网页]   [复制链接]

关闭 IDEA 后仍可访问                 设置
```

内置方式的底部说明改为“关闭 IDEA 后远程访问会停止”。二维码、链接、当前项目使用同一份进入地址；不再拆成“手机使用”和“电脑使用”两个大区块。已连接时首页没有安装、重启、停止服务按钮。

只保留一个“设置”入口，进入后按行展示：

- 运行方式：内置 / 独立，右侧“更改”；保留用户已确认的随时切换与重启生效。
- 独立后台版本：当前版本，右侧“检查更新”；有新版时显示版本与“更新”操作。
- 项目管理：进入现有项目列表，按当前模式保留实际可用的管理操作。
- 暂停远程访问：保留现有控制行为，不把它与停止后台混作一个动作。
- 故障排查：按需展开连接详情、重启与停止后台；已停止时显示启动。

## 首次设置与状态

首次仍提供两种方式，沿用现有默认与已保存的选择，用结果描述差别：

- 随 IDEA 运行：无需安装。
- 关闭 IDEA 后仍可使用：需要安装独立后台。

选择独立方式后自动检测；未安装时按钮为“安装并继续”。下载、校验和安装由程序执行，完成后按现有交接机制提供“重启 IDEA 并继续”，重启回来继续原设置。已配置用户不再重复看到首次选择。

首页只呈现当前最需要处理的状态：

| 当前情况 | 主操作与反馈 |
| --- | --- |
| 独立后台未安装 | 安装并继续，原位显示进度与结果 |
| 需要重启完成切换 | 重启 IDEA 并继续 |
| 后台未启动或启动失败 | 启动 / 重新启动；详情折叠，不显示开启远程的按钮 |
| 后台已就绪但未登录连接 | 开启远程访问；确需登录时进入现有登录流程 |
| 等待用户完成登录 | 继续登录，成功后自动进入二维码页面 |
| 远程访问已暂停 | 开启远程访问 |
| 网络连接中断 | 说明连接中断及自动恢复状态，提供检查连接 |
| 已连接 | 二维码、打开网页、复制链接 |

同一次错误只在对应操作附近说明一次，技术详情按需展开。保持连接状态和服务状态的真实区别，但首页由程序决定下一步，不要求用户自行组合判断。

## 更新方式

打开远程设置时自动查询 GitHub Releases，也提供手动“检查更新”。从独立后台 Release 中找到适用当前平台的版本和安装资产，不再把更新目标固定在插件常量中。

检查更新不打断聊天或远程连接；用户点击更新后才下载安装，沿用校验、数据保留和重启续接机制。更新提示、进度和错误统一留在设置的版本行，移除弹窗外的大幅更新横幅。旧网页接入新插件时也必须有可用的原生检查入口。

独立浏览器也提供检查更新与新版 Release 链接；自动下载安装通过 IDEA 的远程设置执行。

以后后台升级只发布独立包；插件自身改变时才发布插件。安装器接口有实际变化时再处理兼容，不提前增加多个版本通道或降级策略。

## 验收重点

- 首次使用和已配置用户走各自流程；安装后有明确下一步。
- 服务未运行时不能进入连接流程；失败恢复成功后继续到可访问状态。
- 已连接首页只有访问相关操作；管理/设置入口不重复。
- 当前项目链接与二维码保持一致，进入后可切换项目。
- 新后台 Release 发布后，保持原插件不变即可发现和更新；检测失败可在同一行重试。
- 更新失败保留旧版；完成后保留项目、会话和远程设置续接。
- 中文/英文、窄屏/桌面、深浅色一次集中检查，验证各状态按钮与文字。
