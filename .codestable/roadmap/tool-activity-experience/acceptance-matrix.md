# 工具活动体验验收场景

对应 [roadmap](tool-activity-experience-roadmap.md)。下表是整体的验收契约，不表示当前全部已通过；各子 feature 的 acceptance 记录实际结果与证据。

F1–F6 已完成，具体证据见 [F1 验收](../../features/2026-09-14-activity-compact-rows/activity-compact-rows-acceptance.md)、[F2 验收](../../features/2026-09-14-activity-native-facts/activity-native-facts-acceptance.md)、[F3 验收](../../features/2026-09-14-activity-semantic-summaries/activity-semantic-summaries-acceptance.md)。F4 证据见 [历史一致性验收](../../features/2026-09-14-activity-history-parity/activity-history-parity-acceptance.md)。当前已覆盖轻量活动、原生事实/终态/耗时、共用语义摘要及历史/缓存一致性；底部两项计时和特殊交互回归通过。F5 证据见 [详情生命周期验收](../../features/2026-09-14-activity-detail-lifecycle/activity-detail-lifecycle-acceptance.md)，已验证展开选择、请求协调、阅读与复制。F6 的 [连续分组验收](../../features/2026-09-14-activity-segment-grouping/activity-segment-grouping-acceptance.md) 已覆盖 G01–G13。F7 [部分验收](../../features/2026-09-14-activity-ide-readiness/activity-ide-readiness-acceptance.md) 已完成浏览器组合、性能、构建与真实 Codex；Claude 实测超时，IDEA/JCEF 交互未完成，整体尚未通过。

## 1. 固定对照材料

G0/F1 design 阶段建立同一份脱敏演示对话，包含进展文字、普通命令、读取、搜索、MCP、文件修改、执行失败、审批/提问和最终回答；Codex 与 Claude 分别有对应协议样例。

参考用户提供的三张 Codex 截图及当前产品截图，保留“截图可证实”和“本项目新增规则”的区别。截图使用同一显示比例与相同内容比较，不直接按不同尺寸图片推断像素尺寸。

## 5. IDEA、主题与性能

以下为本项目已批准的验收基线，不是 Codex 桌面端测量值。阶段 design 可依据真实 IDEA 可用宽度微调，变更需记录。

| ID | 检查 | 通过标准 |
| --- | --- | --- |
| V01 | 320 / 375 / 480 / 720 CSS px 内容宽度 | 页面无横向溢出；长文本局部省略/滚动；详情入口可达 |
| V02 | IDE 亮色与暗色主题 | 不出现不可读灰字或硬编码亮色块，正文层级高于普通活动 |
| V03 | 100% 与 150% 字号/缩放 | 无裁切、按钮重叠或焦点不可见 |
| V04 | Tab、Enter、Space 操作展开 | 焦点可见，正确 aria-expanded；状态不能只靠颜色判断 |
| V05 | 文字对比与点击目标 | 普通小字对比度目标至少 4.5:1；折叠入口交互区域至少 24×24 CSS px |
| V06 | 1,000 条合成活动历史 | 折叠态完整详情请求为 0；分组/摘要计算不扫描大日志；报告同机基线及变化，不凭感觉宣称更快 |
| V07 | 单条 1 MiB 日志与连续更新 | 大文本仅详情加载/渲染；收起时不创建日志 DOM，不重复追加全量内容 |
| V08 | 协议重放和组件生命周期 | 既有 session-activity / stream / approval / question 重点回归通过 |
| V09 | IDEA/JCEF 本地包 | 主题、缩放、焦点、复制与详情滚动均有真实 IDE 证据 |
| V10 | 两种原生 CLI | 各有一轮覆盖普通工具、完成/失败、历史返回的实测；不将协议 fixture 当作真实 CLI 测试 |

性能先采用结构性检查（请求数、DOM、重复计数、缓存边界）和同机基线比较，不在未测量前承诺固定帧率或响应时长。只有发现实际瓶颈时，才在相应 feature 内明确虚拟化等实现选择。
