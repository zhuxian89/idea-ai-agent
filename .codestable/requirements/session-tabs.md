# 多会话标签切换

## 用户故事

- 同时让两三个 Agent 会话工作时，我希望一眼看到已经打开的会话，直接点击切换，而不是反复打开历史页寻找。
- 会话仍在运行时，我希望沿用熟悉的呼吸灯判断进度；完成后入口继续留着，方便马上查看结果。
- 暂时不看某个会话时，我希望只关闭它的标签，不停止任务、不删除历史，之后还能从历史页重新打开。
- 需要找旧会话时，我希望搜索框一直可见，输入第一个字符就开始筛选，不需要先点图标或再按回车。

## 为什么需要

系统已经能让多个会话同时运行，但正在进行的几个会话缺少像编辑器文件那样直接、稳定的工作入口。每次回历史列表定位会打断节奏，也让已有并行能力显得不够原生。

## 怎么解决

主聊天区域提供一排 IDEA 风格会话标签。打开历史会话或首次发送新会话时自动加入；点击标签直接显示对应内容，运行状态用现有呼吸灯表达。少量标签平分并占满可用宽度，优先展示标题；标签较多时才提供紧凑滚动。聊天态不再重复显示会话大标题；用户消息摘要放在输入框上方的当前会话操作行，并显示“消息 N”以明确作用域。关闭标签只收起这个视图。历史页使用常驻的整行搜索框，输入即搜并支持一键清空。

## 边界

- 标签只管理当前应用生命周期内的打开视图，不负责启动、停止、删除或持久化会话。
- 历史页继续显示全部会话并提供搜索，不按“正在运行 / 最近”重新分组。
- 第一版不跨 IDEA 重启恢复打开标签，也不新增后端状态或会话协议。
- 这项能力只改善多会话切换，不替代 IDEA 的文件 Diff、回滚或版本管理工具。
