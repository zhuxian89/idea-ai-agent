# 本轮文件修改的对比查看

## 用户故事

- 一轮 Agent 对话结束后，我在聊天里点击本轮修改的文件，希望直接看到左右对照的代码，而不是只读一段 unified diff。
- 修改较大时，我希望能打开 IDEA 原生对比窗口，用熟悉的左右分栏、语法高亮和滚动方式复核这轮改动。
- 过一段时间再回看历史对话，我希望看到的仍是那轮开始前和结束后的内容；之后我自己继续改文件，不应改变这轮的对比结果。
- 我希望这个查看动作只读，不触发 Agent 继续执行，也不修改项目文件或 Git 状态。

## 为什么需要

现在本轮文件列表已经能说明“改了哪些文件”，但选中文件后只有单栏 diff。改动多行或需要上下文时阅读成本高，也缺少 IDEA 用户熟悉的原生对比体验。

## 怎么解决

聊天卡片继续显示本轮文件列表和统计；选中文件后默认提供左右分栏视图，并提供“在 IDEA 中对比”入口。新记录会保存这轮前后的内容快照，打开 IDEA 对比时使用这份固定快照。旧记录或快照不可用时，仍保留现有 diff 展示，不伪造历史内容。

## 边界

- 本能力只做查看，不修改文件、Git 状态、Agent 会话、工具、权限或提示词。
- 左右分栏可从已保存的 unified diff 渲染；IDEA 原生对比需要新增快照数据，旧版本产生的记录没有该数据时入口降级。
- 超大、二进制、不可读取或部分观察失败的文件按可诊断的降级处理，不阻断 Agent 对话和现有 diff 列表。
- 它不是 Git 提交历史查看器；对比对象是“本轮开始前 → 本轮结束后”的工作区状态。
