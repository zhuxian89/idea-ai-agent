# 重装后 Agent 显示问号，需要手动操作才能识别模型

## 1. 现象

用户报告每次重新安装后 Agent 列表出现黄色问号，需要点击后才能识别模型。补充截图 `image (12).png` 明确显示 Claude 的错误详情为 `probe pending`。此前截图 `image (11).png` 中多个 Agent 都没有模型展开入口。

## 2. 复现步骤

1. 启动或重新安装插件后启动运行时。
2. 打开输入栏的 Agent 选择器。
3. 展开黄色问号，看到 `probe pending` 被列为错误。

代码可确定的持续复现路径：Windows 启动时只检查命令存在，禁用后续能力探测；必须手动重启 Agent 才触发 `ProbeOne`。macOS/Linux 在探测进行期间也会短暂显示同一伪错误。用户尚未明确截图所在操作系统，不能据此断言截图一定来自 Windows。

## 3. 期望行为

启动后自动识别已安装 Agent 的模型和选项。等待期间有明确的加载提示；完成后界面自动更新。真实启动、登录等错误保留错误详情和恢复入口。

用户后续补充：问号的含义与可点击性都不清楚，必须点开才能看见原因，属于交互设计问题。错误状态和简短原因应直接可见，额外详情及恢复操作使用明确的文字入口。

## 4. 环境与范围

- 当前开发分支：`main`，基线 `4e0a829`，已发布版本 `0.1.14`。
- 涉及共享 Agent 探测、HTTP/WebSocket 状态和选择器，适用于 Codex、Claude 和 ACP 传输。
- 本轮在 macOS 上开发验证；Windows 仅做交叉编译，未实机安装验证。

## 5. 判定

P2 初始化及状态显示问题，不涉及会话内容或模型配置损坏。点问号只展开详情，本身不会请求模型；手动重启按钮才会再次探测。按当前报障继续完成可逆修复。
